How radios verify

In plain words

  1. Every radio is built with our root key. It is a public key, written once onto the radio. The matching private key stays offline and never touches the internet.
  2. The root key vouches for the working keys. The keyring on this site lists the keys allowed to sign releases and channels. A radio only accepts a keyring signed by the root key, and only a newer one than it already has.
  3. Each release is signed. The release key signs release.json, which names the exact software file and its SHA-256. A radio refuses a file whose checksum does not match, byte for byte.
  4. Channels say which release to take. A short, signed channel index points Bench, Beta or Stable at one release. It expires after two weeks and is re-signed every day, so nobody can replay an old one to hold a radio back.
  5. Install, test, or go back. The radio installs next to the running version, checks its own health and keeps the new version only if everything works. Otherwise it returns to the previous one by itself.
